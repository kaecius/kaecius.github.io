2. Code

Inline Code

Use backticks for inline code: const x = 1, npm run build, git commit -m "msg".

Fenced Code Blocks

Use triple backticks with a language identifier for syntax highlighting.

JavaScript

function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}

const result = fibonacci(10);
console.log(`Fibonacci(10) = ${result}`);

SQL

SELECT
  u.name,
  COUNT(o.id) AS order_count,
  SUM(o.total) AS total_spent
FROM users u
LEFT JOIN orders o ON u.id = o.user_id
WHERE u.created_at >= '2026-01-01'
GROUP BY u.id, u.name
HAVING COUNT(o.id) > 5
ORDER BY total_spent DESC
LIMIT 10;

MDX allows raw HTML alongside Markdown. Useful for elements Markdown doesn’t support.

  year: "numeric",
  month: "long",

})}

6. Components

Importing Components

In MDX files, you can import Astro or React components and use them directly:

import Callout from '../../components/blog/Callout.astro';
import CodeGroup from '../../components/blog/CodeGroup.astro';
import { Button } from '../../components/ui/Button';

Custom Callout Boxes

Below are callout-style boxes built with styled <div> elements. These demonstrate how to create component-like patterns using inline HTML + CSS classes.

Info: This is an info callout box. Use it for general information, context, or background details that help the reader understand the topic.

Warning: This is a warning callout box. Use it to highlight potential pitfalls, deprecations, or things that could go wrong if the reader isn’t careful.

Danger: This is a danger callout box. Use it for critical information — data loss risks, security vulnerabilities, or irreversible operations.

Tip: This is a tip callout box. Use it for helpful shortcuts, best practices, or pro tips that improve the reader’s workflow.

Using Fragments

Fragments let you group elements without adding a wrapper DOM node:

  <p>Second paragraph — no extra wrapper div.</p>
</>
