## 1. Standard Markdown

### Headings

Use `##` for sections and `###` for subsections. Avoid `#` — the post title already serves as h1.

```markdown
## Second-level heading
### Third-level heading
#### Fourth-level heading
##### Fifth-level heading
###### Sixth-level heading
```

#### Fourth-level heading
##### Fifth-level heading
###### Sixth-level heading

### Paragraphs

Regular paragraphs are just lines of text separated by blank lines. You can write long-form content here without any special syntax.

This is a second paragraph. Each block of text separated by a blank line becomes its own `<p>` element.

### Text Formatting

**Bold text** using double asterisks.

*Italic text* using single asterisks.

***Bold and italic*** using triple asterisks.

~~Strikethrough text~~ using double tildes.

### Links

[External link](https://example.com) using standard Markdown syntax.

[Link with title](https://example.com "Hover title") with an optional title attribute.

### Images

Images support alt text, which is important for accessibility.

#### JavaScript

```javascript
function fibonacci(n) {
  if (n <= 1) return n;
  return fibonacci(n - 1) + fibonacci(n - 2);
}

const result = fibonacci(10);
console.log(`Fibonacci(10) = ${result}`);
```

FROM users u

WHERE u.created_at >= '2026-01-01'
GROUP BY u.id, u.name
HAVING COUNT(o.id) > 5
ORDER BY total_spent DESC
LIMIT 10;

## 5. JSX Expressions

### Inline Expressions

Basic arithmetic: {1 + 1}

String operations: {"hello".toUpperCase()}

Current year: {new Date().getFullYear()}

### Conditional Rendering

{true ? "This text is visible because the condition is true." : "This won't show."}

{false ? "Hidden" : "This shows because the condition is false."}

### Template Literals in JSX

{"This post was written on " + new Date().toLocaleDateString("en-US", { weekday: "long", year: "numeric", month: "long", day: "numeric" })}

### Variable Interpolation from Frontmatter

In Astro content collections, access frontmatter via the `props` object in `.mdx` files:

```mdx
---
title: "My Post"
date: 2026-07-13
tags: ["astro", "mdx"]
---

Title: {props.title}
Date: {props.date}
Tags: {props.tags.join(", ")}

Formatted date: {new Date(props.date).toLocaleDateString("en-US", {
  year: "numeric",
  month: "long",
  day: "numeric"
})}
```

## 7. Frontmatter Integration

### Accessing Frontmatter Data

In Astro content collections, frontmatter is available via `props` in `.mdx` files:

```mdx
---
title: "My Post"
date: 2026-07-13
tags: ["astro", "mdx"]
---

Title: {props.title}
Date: {props.date}
```

### Date Formatting

Example of formatting dates from frontmatter:

```mdx
Raw date: {String(props.date)}

Formatted: {new Date(props.date).toLocaleDateString("en-US", {
  year: "numeric",
  month: "long",
  day: "numeric"
})}
```

## 8. Advanced Patterns

### Nested JSX with Children

<div class="callout callout-tip">

**This is a nested JSX pattern.**

You can put full Markdown inside JSX elements, including:

1. Ordered lists
2. With multiple items

And even `inline code` or code blocks:

### Spreading Props

You can spread objects as props onto components:

```mdx
---
calloutProps:
  type: "warning"
  title: "Be careful"
---

<Callout {...props.calloutProps} />
```

### Using Fragments

Fragments let you group elements without adding a wrapper DOM node:

```mdx
<>
  <p>First paragraph in a fragment.</p>
  <p>Second paragraph — no extra wrapper div.</p>
</>
```

### MDX Comments

Use JSX comment syntax to add comments that won't render:

{/* This comment won't appear in the rendered output */}

{/* 
  Multi-line comments work too.
  Use these for notes, TODOs, or reminders
  that only editors should see.
*/}

## 9. Footnotes

MDX supports footnotes through the remark-gfm plugin[^1]. You can also use multiple footnotes in the same document[^2].

[^1]: This is the first footnote. It appears at the bottom of the page.
[^2]: And this is the second footnote. Footnotes are automatically numbered and linked.

## 10. Math / KaTeX

Math rendering is **not currently configured** in this blog, but it can be added with:

- `remark-math` — parses `$...$` and `$$...$$` syntax
- `rehype-katex` — renders parsed math into HTML with KaTeX

Once configured, you'd write:

```markdown
Inline math: $E = mc^2$

Block math:

$$
\sum_{i=1}^{n} i = \frac{n(n+1)}{2}
$$
```
