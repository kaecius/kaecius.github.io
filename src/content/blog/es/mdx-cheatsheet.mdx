## 1. Markdown Estándar

### Encabezados

Usa `##` para secciones y `###` para subsecciones. Evita `#` — el título del post ya sirve como h1.

```markdown
## Encabezado de segundo nivel
### Encabezado de tercer nivel
#### Encabezado de cuarto nivel
##### Encabezado de quinto nivel
###### Encabezado de sexto nivel
```

#### Encabezado de cuarto nivel
##### Encabezado de quinto nivel
###### Encabezado de sexto nivel

### Párrafos

Los párrafos regulares son simplemente líneas de texto separadas por líneas en blanco. Puedes escribir contenido extenso aquí sin ninguna sintaxis especial.

Este es un segundo párrafo. Cada bloque de texto separado por una línea en blanco se convierte en su propio elemento `<p>`.

### Formato de Texto

**Texto en negrita** usando doble asterisco.

*Texto en cursiva* usando asterisco simple.

***Texto en negrita y cursiva*** usando triple asterisco.

~~Texto tachado~~ usando doble tilde.

## 7. Integración con Frontmatter

### Acceder a Datos del Frontmatter

En el frontmatter:
```yaml
---
title: "Mi Post"
date: 2026-07-13
author: "Daniel"
---
```

En el cuerpo MDX (en layouts Astro):
```mdx
Título: {Astro.props.frontmatter.title}
Fecha: {Astro.props.frontmatter.date}
```

### Formateo de Fechas

```mdx
{new Date(Astro.props.frontmatter.date).toLocaleDateString('es-ES', {
  year: 'numeric',
  month: 'long',
  day: 'numeric'
})}
```

## 9. Footnotes

Los footnotes se soportan mediante el plugin remark-gfm[^1]. También puedes usar múltiples footnotes en el mismo documento[^2].

[^1]: GitHub Flavored Markdown extiende Markdown estándar con características adicionales.
[^2]: Los footnotes se renderizan al final del documento.

## 10. Math/KaTeX

Para soporte de matemáticas, necesitas instalar plugins adicionales:

- `remark-math` — parsea sintaxis `$...$` y `$$...$$`
- `rehype-katex` — renderiza matemáticas en HTML con KaTeX

Ejemplo de uso:
```mdx
La ecuación de Einstein: $E = mc^2$

Ecuación en bloque:
$$
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
$$
```
